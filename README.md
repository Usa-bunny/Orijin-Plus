## 🚀 Getting Started

### Installation
1. Clone the repository:
~~~bash
git clone https://github.com/Usa-bunny/Orijin-Plus.git
cd Orijin-Plus
~~~
2. Install Dependencies
```bash
npm intall
```
3. Run
```bash
npm run watch:sass
```
